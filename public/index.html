TRMNL PLUGIN

Rebigulator Daily

Put today's Rebigulator frame and quote on your TRMNL. Scan the QR code when you want to reveal the episode.

Play Rebigulator Online

Polling endpoint

GET /api/daily

The endpoint uses Rebigulator's daily challenge algorithm and public API to select the same first frame shown at rebigulator.org.

No API key or authentication is required.
